# LifeLink - Jeevan Dhara 🩸

A blood donation awareness website that helps people find compatible blood, check donor eligibility, and locate blood banks across NCR.

## Features
- Donor eligibility checker (age, weight, recent illness, last donation gap)
- Blood group compatibility and donor matching
- Blood bank directory with map links
- Donor registration and health card

## Built with
HTML, CSS, JavaScript

## Note
This is a student project . Donor and blood bank data is demo data, not live blood stock.
